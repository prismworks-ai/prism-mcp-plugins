# prism-mcp-plugins

This repository currently contains repository/contribution documents, not an implemented plugin catalogue. There are no verified plugin downloads, coverage results or production installation claims in this review.

Keep the repository reserved for a small number of runnable adapter examples when a supported integration needs them. Do not build a marketplace or duplicate the SDK's plugin lifecycle. Native plugins are trusted code unless a separate isolation mechanism is implemented and verified.

See [product strategy](docs/product-strategy.md) and [implementation plan](docs/implementation-plan.md). Existing licensing and contribution terms remain in force.
